# Chassis make-pack

Everything a fabricator needs to build the frame. Generated by `../make_pack.py` from the same nodes, members and tube sizes as the solver (`../frame.py`); checked by `../verify_pack.py`.

| File | What it is |
|---|---|
| `drawings.pdf` | A3 sheets: summary and notes, side view, top and front views (1:4), tube table, inspection distances and jig posts, plates and engine-mount detail |
| `chassis_cut_ready.step` | 3D model: 39 coped tubes (separate named solids), 9 plates with tube holes, 4 spacers, engine clearance boxes for reference |
| `tubes/<id>.step`, `tubes/<id>.dxf` | One coped tube each (straight along Z) and its flat pattern, for tube-laser shops |
| `tube_table.csv` | Every tube: size, centreline length, **long-side length (cut square to this)**, short side, notch depth at each end, which tubes it is coped onto |
| `notch_templates.pdf` | 1:1 wrap-around templates for hand coping (print at 100%, check the 50 mm scale bar) |
| `plates.dxf` | Plate flat patterns with bolt holes and tube holes (supersedes the plate patterns in `../frame.dxf`) |
| `BOM.csv` | Tube (with 6 m stock count), plates, spacers, bolts, filler, coating |
| `jig_table.csv`, `jig_table.dxf` | Node posts for a flat jig table: x, y on the table and post height |
| `verify_pack.json`, `results_pack.json` | Check results |

Lengths: the long-side length is measured tip to tip on the outside surface of the tube. A hand-coped tube follows the outer line, so the inside edge of the wall differs by a few millimetres at shallow angles; that is normal.

See `CHECKLIST.md` for the build order, inspection and the details that are still open.
